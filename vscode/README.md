# Petamori Themes

A collection of color themes by Petamori, built around pink.

| Theme   | Variants                   | Description                                                                 |
| ------- | -------------------------- | --------------------------------------------------------------------------- |
| Peony   | Peony Dusk, Peony Dawn     | A calm, dusty pink with soft pastel syntax colors.                          |
| Fuchsia | Fuchsia Dusk, Fuchsia Dawn | Near-black and near-white canvases with a vivid hot pink as the main color. |
| Berry   | Berry Dusk, Berry Dawn     | Pink canvases: deep berry for Dusk, cherry-blossom paper for Dawn.          |

Dusk variants are dark themes, and Dawn variants are light themes.

All colors are generated from a shared palette, and text colors are checked against WCAG 2 contrast ratios.

The same themes are also available for [Zed](https://zed.dev).
